Implementación de un Chat Básico Cliente-Servidor con Sockets y Base de Datos
 Configuración de un servidor de sockets en Python que recibe mensajes de clientes,los guarda en una base de datos y envía confirmaciones.

**Tecnologías utilizadas:** Python, sockets TCP/IP, SQLite
**Estructura:**
chat_clienteServidor/
│
├── chat.db
├── cliente.py
└── servidor.py

**Instrucciones:**
1. Ejecutar servidor.py
2. Ejecutar cliente.py en otra terminal
3. Ingresar mensajes desde el cliente
4. Escribir "éxito" para finalizar
5. Los mensajes quedan almacenados en chat.db
